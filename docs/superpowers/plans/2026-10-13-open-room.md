# Open-room correction

User correction: pair cards are not a shared 2.5D room; people should wander and discuss with anyone dynamically. Continuing prior explicit build-with-defaults approval; no additional preference interview.

## Accepted direction
One shared isometric room, upright local SVG people projected onto one floor, depth sorting, extruded walls/floor/props, continuous movement interpolation. No separate conversation cards or permanent partners. Backend owns world positions and encounter reservations; browser renders the same state rather than decorative random motion unrelated to conversation. Preserve live SDK/SSE, ten-agent cap, one spoken turn per agent per cycle, sequential dependent response, max four independent encounters, saved runs/summary/cancel and cost ceiling. Movement/encounter selection uses standard-library randomness, not extra LLM calls. Random proximity-driven selection is a heuristic, not autonomous model-controlled navigation.
