## Design
- Maintain 1..10 agents/rounds and 2 + agents*rounds logical-call ceiling. Rotating pairing each round gives new conversation partners. Each agent speaks once: pairs execute concurrently (up to four workers), their two turns sequentially. Respondent must answer the partner's completed non-pass turn; cannot reply to self, invisible, partial or failed text. Odd agent has a solo opening. Independent pairs share only prior-round committed context, not each other's unfinished turns.
- Streaming uses official Responses SDK stream(text_format=Schema). Native Pydantic partial JSON parser extracts human text fields from genuine provider deltas, not a fake typewriter or raw JSON. Draft text is unvalidated and labeled as such; only finalized schema/target-validated turns become cited evidence. No hidden chain-of-thought exposed.
- Each completed turn immediately checkpointed; dependency order retained. Cancellation closes in-flight SDK streams when observed and starts no further turns/report; preserve committed turns, discard drafts. Interrupted runs never replay paid calls. Round count means fully finished rounds, partial round retained on failure/cancel.
- One durable SQLite event table with monotonic IDs, JSON event payloads and run FK. Condition notifications for EventSource readers; same-origin GET /api/runs/{id}/events with Last-Event-ID or after cursor, heartbeats, terminal close, bounded clients. Streams replay events and draft lifecycle; transcript snapshots authoritative after reconnect/restart. GET never launches model work. Completed actions and their completion event saved atomically.
- Events: state, turn_start, turn_delta (cumulative text), turn_complete (action), turn_abort, report_start, report_delta (fields), report_complete, terminal. Turn metadata: turn_id, agent_id, partner_id, round, lane, reply_to. UI uses stable IDs and stream closure, never duplicate generation. Four SDK calls max; no new runtime dependency.
- Vanilla SVG/CSS human figures in a perspective room: faces, hair/clothes, floor/shadows; buttons identify/select agents, speaking/listening/idle cues and bubbles. No simulated real person's likeness. Independent lanes show simultaneous speech; sequential replies show addressed partner and reply link. Reduced motion and text transcript remain fully usable. Old saved runs can be replayed, clearly marked recorded playback, never claimed live tokens.
- Room + conversation + final synthesis tabs; summary preview/jump near status; automatic selection of synthesis when generation begins, no forced viewport jumps. Report streams summary and clear outcomes; new report fields agreements, disagreements, open_questions, conclusion with bounded text; old report schemas still render. Findings retain valid evidence citations and explicitly distinguish viewpoints from forecast.
- Privacy/security stays localhost-only, no key in payload/DOM, textContent rendering, security headers, bounded event text, prepared consent, no external avatar service.
